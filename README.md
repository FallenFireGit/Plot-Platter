# Plot-Platter
A CoreXY-inspired pen plotter gantry. Designed with the intent to be mostly 3D printed while still maintaining high rigidity through tight tolerances. This is only V1 of this project; I intend to reproduce this and test it in later revisions. Also, no AI was used in this project, aside from Grammarly for the README.

### Bill of Materials
- 13 M3 Screws (Length doesn't matter, but ~16 mm should work for all holes besides the clam, which requires 32 mm)
- NEMA 17 Stepper Motors + Drivers
- GT2 Belts & Pulleys
- 3D Printer (PLA works, just beware of warping)

### Production
- I don't have a 3D printer, but if you want to physically make this (which I wouldn't recommend since it's a V1), using the standard Bambu Labs default settings is what I would use. Nothing special needs to be done to the prints
